# 01: Esqueleto andante

**What to build:** Un Learner elige un Role y marca algunas Skills en una página web mínima, y recibe un Learning path de un mini-catálogo de 5 Skills escrito a mano. Atraviesa todas las capas (motor, interfaz y prueba) para que el equipo tenga una base ejecutable sobre la que crecer. Incluye dejar listos el paquete del motor, el entorno y la forma de correr pruebas.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Existe un único punto de entrada que recibe un Learner profile y devuelve un Learning path
- [ ] La página web llama a ese punto de entrada y muestra el resultado
- [ ] Al menos una prueba pasa llamando al punto de entrada con un perfil de ejemplo
- [ ] El entorno se instala y la app y las pruebas se ejecutan con comandos documentados en el README
- [ ] El código y los archivos están en inglés y usan el vocabulario de `GLOSSARY.md`

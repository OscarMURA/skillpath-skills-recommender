# 04: Prerequisites, Effort y Mastery level

**What to build:** El Learner indica su Mastery level en cada Skill conocida y el Learning path se vuelve personal: excluye lo que domina (desde intermedio), mantiene lo de nivel básico como candidato para profundizar, pone cada Skill después de sus Prerequisites y prioriza alta Frequency con bajo Effort.

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] Quien domina una Skill (intermedio o avanzado) no la recibe; con nivel básico sí puede recibirla
- [ ] Una Skill nunca aparece antes de sus Prerequisites faltantes
- [ ] Una Skill muy frecuente pero muy costosa baja frente a otra igual de frecuente y más alcanzable (caso de prueba)
- [ ] La misma entrada produce siempre el mismo resultado
- [ ] La fórmula de prioridad queda documentada y **firmada por un humano** (compuerta)

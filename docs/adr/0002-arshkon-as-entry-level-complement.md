# arshkon como complemento de nivel junior por búsqueda en el texto

Los tres datasets de asaniczka solo tienen ofertas Associate y Mid senior, y el público objetivo incluye estudiantes y recién graduados. arshkon sí trae ofertas de nivel Entry, pero sus habilidades son 35 categorías amplias (ACCT, MRKT...) inútiles para Skills técnicas. Decidimos usarlo solo como complemento: detectar las Skills del Catalog en el texto de `description` mediante búsqueda por diccionario y calcular la Frequency para ofertas de nivel inicial.

La muestra junior por Role es pequeña (≈58 a 210 ofertas), por eso asaniczka sigue siendo la base. rajatraj0502 no se usa: tiene el mismo problema de categorías amplias.
